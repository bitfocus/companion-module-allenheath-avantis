# companion-module-allenheath-avantis

Bitfocus Companion module for Allen & Heath Avantis consoles running firmware 2.0 or newer.

The module provides documented MIDI/TCP control plus optional console synchronization, Avantis 2.0/dPack capacities, RackUltraFX support, automatic console discovery, scene workflows, timed fader moves, and production-oriented feedback.

This is an independent community module. It is not endorsed or supported by Allen & Heath. Optional AH-Net functionality uses Allen & Heath proprietary, internal behavior that may change or become unavailable in future firmware.

See [Module Help](./companion/HELP.md) for setup, features, operational limitations, and permission guidance.
